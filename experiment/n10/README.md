# N10 본 실험 분석 입력

담당 김태형. 본 실험(블라인드 프로토콜 복원)에 쓰는 분석 입력이다. 소스·기준 명세·정답표·숨은 평가 입력은 김태형·권세현이 저장소 밖에 보관하며, 초기 평가가 고정될 때까지 공개하지 않는다. 이 문서에는 프로토콜에 관한 정보를 적지 않는다.

## 실행

저장소 루트에서 N05 이미지로 실행한다. 인자는 `[port]`(기본 19010)이고 `127.0.0.1`에만 바인드한다. 클라이언트는 같은 컨테이너(같은 네트워크 네임스페이스)에서 `127.0.0.1`로 접속한다.

    docker compose -f compose.n05.yaml run --rm n05 sh -c 'experiment/n10/n10-server 19010 & sleep 1; <클라이언트 명령>; kill $!'

## 분석 조건

- 패킷만: `sessions.pcap`
- 패킷+바이너리: `sessions.pcap`과 `n10-server`

이 README와 저장소의 다른 문서를 분석 모델 입력에 넣을지는 N09 실행 기록에 남긴다.
